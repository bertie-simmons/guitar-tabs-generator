# guitar-tabs-generator
A web application that generates guitar tablature, from a uploaded video, through pitch detection and hand tracking.

> [!warning] Usage of AI (for employers)
> Claude code's Impeccable skill was used to generate the frontend. I decided to do this as I have built many projects with React and I wanted to focus on the backend.
> 
> Some documentation found in this project is also generated by AI.

## What I am currently working on...
